# 暗渊城堡 · Dark Abyss Keep

竖屏单手操作的暗黑地牢风格放置 RPG，纯前端实现（HTML/CSS/原生 JS），零依赖，打开即玩。

## 运行

直接用浏览器打开 `index.html` 即可（推荐手机模式 / 窄屏窗口，如 400x800）。
存档保存在 localStorage，关闭页面自动保存，再次打开自动结算离线收益。

## 界面布局

- **资源信息区**（顶部）：金币 / 钢铁 / 钻石 / 魂火 / 建材
- **城堡管理区**（上半部）：庄园、招魂塔、铁匠铺、冒险者公会 四座建筑分布展示，点击进入管理
- **冒险地图区**（中部）：节点式地图，含战斗 / 精英 / 宝箱 / 事件 / 休整 / BOSS
- **队伍状态栏**（底部）：英雄头像、生命条、技能冷却，战斗中点击头像释放技能

## 核心玩法

1. **资源管理与挂机收益**：庄园产铁+建材、招魂塔产魂火+灵魂经验；在庄园中分配人口到工匠/侍僧岗位控制产出；离线最多结算 8 小时收益。
2. **地牢探险与随机事件**：箱庭节点地图逐行解锁；随机事件（神秘路人、诡谲陷阱、古老祭坛、流浪铁匠）需即时抉择。
3. **英雄招募与职业养成**：公会金币抽卡（N/R/SR/SSR）；6 大职业体系、53 种职业；**灵魂等级**（全员共享）与**锻造等级**（装备共享）降低重复养成负担。
4. **即时策略战斗**：自动普攻 + 手动技能 + **战吼大招**（充能满后全队回血、技能重置、敌全体扣血）；BOSS 血量低于 30% 进入狂暴阶段，伤害翻倍。
5. **装备打造与铁匠铺**：消耗钢铁批量打造，铁匠铺升级提高极品率；低品质装备可通过**回火**逐阶提升品质（白→绿→蓝→紫→橙）。

## 文件结构

```
index.html      页面骨架（四大区域 + 战斗层 + 弹窗）
css/style.css   暗黑地牢风格样式
js/data.js      静态数据：职业/英雄/敌人/装备/地图/事件
js/state.js     游戏状态、存档、挂机结算、共享等级
js/combat.js    即时战斗系统
js/ui.js        界面渲染、建筑弹窗、地图探索
js/main.js      入口与主循环
```
